# Networking Labs

Repositório dedicado aos meus estudos e laboratórios práticos de Redes de Computadores.

## Objetivo

Aplicar na prática os conceitos estudados em redes, criando ambientes simulados, realizando testes, analisando protocolos e documentando os resultados.

Este projeto também faz parte do meu portfólio de Infraestrutura de TI.

## Ferramentas

* Cisco Packet Tracer
* Git
* GitHub
* Git Bash
