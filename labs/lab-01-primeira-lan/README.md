# Lab 01 — Primeira LAN

## Objetivo

Criar uma rede local simples utilizando dois computadores e um switch, com o objetivo de compreender como dispositivos da mesma rede conseguem se comunicar.

## Topologia

A topologia será composta por:

* 2 computadores;
* 1 switch;
* conexões Ethernet.

## Conceitos estudados

Durante este laboratório serão analisados:

* IPv4;
* máscara de rede;
* interface de rede;
* endereço MAC;
* ARP;
* ICMP;
* funcionamento básico de switches.

## Endereçamento

O endereçamento será definido durante a implementação do laboratório.

## Testes

Os testes serão documentados após a configuração da rede.
